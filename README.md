# Sensing Drones with Communication Signals

Project page: **https://yunjung-jeong.github.io/Sionna-RT-Simulation/**

A ray-traced digital twin (NVIDIA Sionna RT) of how one radio can detect, track and characterise a drone and its spinning blades with an NR-like OFDM signal.

Ongoing, unpublished research; all results are simulated.
