# Sionna-RT-Simulation

Project page: **Sensing Drones with Communication Signals**, a ray-traced digital twin for drone sensing with a single radio.

**View it at https://yunjung-jeong.github.io/Sionna-RT-Simulation/**

This repository hosts a small static page, served by GitHub Pages from the root of `main`. It describes my ongoing research on integrated sensing and communication (ISAC) for drones: an NR-like OFDM signal, radio channels ray-traced with NVIDIA Sionna RT, and a sensing receiver that turns the echoes into range-Doppler, micro-Doppler and detection maps.

- **Status:** ongoing, unpublished research. Everything shown here comes from simulation; no hardware measurements or real flights are shown.
- **Contents:** the page (`index.html`), its stylesheet (`assets/style.css`) and its figures (`images/`; files ending in `_narrow` are stacked versions for phones). No build step and no external scripts. Code and data are not included at this stage.
- **Author:** Yunjung Jeong, Intelligent Radio Sensing Lab (IRS Lab), Department of Electrical Engineering and Computer Science, DGIST. [CV](https://yunjung-jeong.github.io/cv/)
